# Architecture Decision Records

ADR's leggen belangrijke technische keuzes en hun gevolgen vast. Een geaccepteerd ADR wordt niet stilzwijgend aangepast: een latere koerswijziging krijgt een nieuw ADR dat het eerdere besluit vervangt.

Statussen:

- `Proposed`
- `Accepted`
- `Superseded`
- `Rejected`
