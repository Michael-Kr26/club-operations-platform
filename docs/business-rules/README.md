# Business Rule Catalog

Iedere uit SSO of de praktijk overgenomen regel wordt hier afzonderlijk gevalideerd voordat deze in COP wordt geïmplementeerd.

Een regel bevat minimaal:

- ID;
- bron en vindplaats;
- huidig bewezen gedrag;
- reden voor de regel;
- generiek of tenant-specifiek;
- voorgesteld COP-model;
- acceptatiecriteria;
- tests;
- validatiestatus en eigenaar.

Een ontbrekende of onduidelijke regel wordt niet vervangen door een verzonnen standaard.
